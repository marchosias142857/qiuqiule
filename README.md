# 球球了 · v4.1.0

本次将 GPT Site 的 v4.1.0 同步到 GitHub，包含 v4.0.0 起的选关定位、暂停按钮修复、拉扯轮廓与回弹连续性优化，以及 v4.1.0 点击选关、呼吸与视线跟随。GitHub Pages 使用同一份 `dist/` 游戏资源。保留现有安卓构建配置；已发布安装包见 [GitHub Releases](https://github.com/marchosias142857/qiuqiule/releases)，构建说明见 [Android 文档](docs/ANDROID.md)。

保留 GitHub 版的拖拽起始速度叠加、阶段拖拽阈值、高速细分物理、表情开关、标题摆动、设置/玩法过渡、玩家独立重开/回主页动画、无闪烁入场及核心/附加资源分离离线缓存。所有运行资源位于 `dist/`，无需安装依赖或构建即可静态部署。

## 4.1.0 点击选关与中央球互动

- 选关改为直接点击关卡球进入、点击下方返回球回主页，均有音效反馈；锁球保持未解锁状态并提供轻微弹动与提示音。只检测轨道裁切后可见的球体，保留最高解锁关的默认定位。
- 点击需在同一目标按下/松开且整个手势位移不超过8个CSS像素。超过阈值即作为滑动，不会因松手回到原处而误入关卡；轨道惯性、整数吸附与两端弹性保留。
- 中央玩家球可以直接拉扯，但任意方向/力度均只原地回弹，不再通过碰撞选择关卡或返回。移除选关的所有拖拽提示线、方向点与端点圆圈；战斗提示保持原样。
- 选关中央球复用主页的独立呼吸周期和0.82秒回弹，回弹结束后重新开始呼吸。手指按住屏幕且位于玩家球外时，眼睛轻微看向手指，最大偏移为半径的8%；移入球体、离开屏幕、松手和取消均平滑回正。
- 点击进关保留中央球到局内的0.65秒动画，战斗与刷怪在动画完成后开始；点击时延续实际呼吸与回弹轮廓、表情，避免先跳回圆形。关卡数值、战斗规则与存档格式不变。

## 4.0.2 原地回弹结束衔接

- 主页与选关的原地回弹结束时保留上一帧眼形，再用0.12秒平滑恢复原椭圆，消除表情瞬间替换；直接发射和取消拖拽仍按原规则立即恢复普通表情。
- 主页球在回弹结束时从圆形、呼吸相位0重新开始完整呼吸周期，不再继承旧呼吸进度或旧压缩量；功能球返回、取消拖拽和设置转场结束同样处理。保持原呼吸幅度和频率，主页共用时钟与其他球的动画不重置。
- 所有新增计时均保存在绘制层的独立WeakMap中，不修改球体的模拟属性。原地回弹仍为0.82秒，碰撞后返回仍为0.68秒，可操作时刻、弹射力度、碰撞、关卡数值与存档逻辑保持原样。

## 4.0.1 拉伸轮廓平滑

- 拉伸半球和圆形背半球在交界处的位置、切线和曲率连续，消除拉扯时两侧的折角和肩部突变。
- 主页、选关、无尽和闯关共用这一轮廓，主页与选关松手后的原地回弹也同步平滑。
- 保留背半圆、最大拉伸长度及尖端圆润程度；弹射力度、碰撞、关卡属性及拖拽操作保持原样。

## 4.0.0 选关默认位置与界面修复

- 每次从主页或结算进入选关，最高已解锁关卡优先定位到12点钟正中间；若完整球位无法正对中线，则使用中间偏左的球位；到1或100边界时停在合法端点。整数吸附、惯性滚动和手动浏览保持不变。
- 仅选关界面的方向提示去掉箭头尖端，保留方向点线与拖拽拉线；局内方向箭头保持原样。
- 暂停按钮不再应用通用图标按钮的绿色悬停背景，点击及触屏残留悬停时保持当前主题背景；保留点击缩放与键盘焦点提示。

## 3.0.5 首页球体微调

设置球围绕首页同心圆圆心逆时针移动 4°，靠近音量球并远离模式选择球，直径设为音量球与模式选择球直径的平均值。模式选择球直径缩为 3.0.4 的 90%，距离同心圆圆心增至原来的 108%。音量球基于主题颜色向白色调浅 18%，开始球调浅 8%，球体均保持完全不透明。绘制、碰撞与键盘命中区域共同使用调整后的布局，横竖屏保持一致。

## 3.0.4 首页功能球位置

首页模式选择球移至原设置球的位置，设置球移至原音量球的位置，音量球移至原模式选择球的位置。三个球同步采用新位置原有的大小，图案、功能与颜色随球迁移，碰撞区域与键盘焦点顺序同步。

## 3.0.3 结算入场同步

关卡结算选关球的淡入与重开球、主页球的移动共用同一动画进度，在另外两球到位的同一帧完全实体化。每次进入结算都会从透明重新开始，减少动态效果模式也保持同步。

## 3.0.2 结算淡入与返回球

关卡结算的旗帜选关球与图案整体在 0.24 秒内由透明平滑淡入，不再等待其他功能球转场结束后突然出现。每次结算重新播放，并遵守减少动态效果设置。选关返回球进一步增大，与玩家球和关卡球使用完全相同的直径。主页与结算页的小旗帜保留原有三角旗的形状和比例，从上顶点的锐角轮廓重新做小圆角；旗杆在旗面内部衔接，消除顶部偏平的感觉。

## 3.0.1 选关修复

- 玩家球与轨道关卡球直径均为 v3.0.0 的 1.7 倍，返回球直径为原来的 1.3 倍。轨道加宽并按屏幕减少球数，保持完整球不碰线、不拥挤。
- 用分数字体的实际字形墨迹边界计算每个数字的水平及垂直偏移，让 1–100 的可见数字严格居于球体中心，而非按字体行框居中。
- 选关保持只能从玩家本体起拖。和主页一样，未命中或力度不足时只在原地弹动；开启表情后，回弹全程保留同款圆角表情。碰撞锁球后返回中央。
- 保留 300° 四圆角环形轨道、60° 下方缺口、拖动/惯性滚动、整数吸附、端点弹性、可见区域裁切及 1/100 两端限制。

## 3.0.0 闯关功能

主页浅蓝模式球在圆角小旗帜与 ∞ 之间切换。旗帜进入 100 关选关，∞ 进入无尽模式。数字字体复用分数字体，锁和返回图案与球体共用变换。

`dist/campaign.js` 为 100 关配置有限敌球总数、难度和自动强化。第 1–100 关总敌球从 20 增至 119，刷新间隔从 3.10 秒降至约 0.892 秒，血量从 15 增至 79，同时提高敌球密度和体型。开局两颗计入总数，击杀全部才通关；满场 18 颗结束。每 5–8 击杀自动轮换弹力、密度和体型强化，使用玩家身上冒字及同款受击闪光反馈。

关卡不显示分数。结算按四舍五入的击杀比例从 0% 快速上涨并播放音效；通关 100% 平滑放大。新增旗帜球与重开/主页球组成等边三角形。连续玩家动画覆盖主页→选关、选关→关卡、关卡↔暂停、结算→关卡/选关/主页。

通关记录保存在本机 `qiuqiule-campaign`，依次解锁下一关并在 100 封顶；无尽纪录独立。刷新页面保留设置与解锁，未结束的一局不会保存。

## 最快部署到 GitHub Pages

1. 解压，把本目录内的文件和目录上传到你的 GitHub 仓库根目录，包括 `.github/workflows/pages.yml`。仓库根目录应直接看到 `dist/`、`package.json` 和 `README.md`，不要再套一层 `qiuqiule/`。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 在 **Actions → Deploy 球球了 → Run workflow** 运行一次；以后推送到 `main` 或 `master` 会自动发布。成功后的网址在 Pages 设置页面及工作流部署结果中。

更详细的步骤及不使用 Actions 的方法见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。

## 本地运行

在工程目录执行：

```sh
python3 -m http.server 8080 --directory dist
```

浏览器打开 `http://localhost:8080/`。不要直接双击 `index.html` 使用 `file://`，ES 模块与 PWA 需要 HTTP/HTTPS 环境。

开发检查需要 Node.js 20 或更高版本；这些检查不需要先安装依赖：

```sh
npm run check
npm test
```

## 离线使用

1. 部署后，通过 GitHub Pages 的 HTTPS 地址打开游戏。
