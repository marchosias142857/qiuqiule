## 18 项强化

`u` 为游戏长度单位。上限计算实际获得的层数，展示过但没有选中的强化不会消耗次数。

| 名称 | 类型 / 上限 | 当前效果 |
| --- | --- | --- |
| 弹性十足 | 常规，4 层 | 每层弹射能量乘 1.3；未提高上限时，出手速度封顶 60u/s。满 4 层后解锁“超速”。 |
| 超速 | 常规，2 层 | 每层出手速度上限增加 8u/s，依次为 68、76u/s；仅弹性十足满层后进入池。 |
| 重量级 | 常规，5 层 | 每层密度乘 1.35。质量同步变化，继续使用原有能量与质量的速度、伤害关系。 |
| 橡胶 | 常规，4 层 | 每层撞击最低保速提高 6 个百分点，由 70% 提高至 76%、82%、88%、94%。不降低已有更高保速。 |
| 大一圈 | 常规，2 层 | 直径依次为原始大小的 1.2、1.4 倍，不是连续乘 1.2；只改变尺寸，不增加质量。 |
| 磁吸 | 常规，2 层 | 击杀后 0.4 秒内，将最近一颗可碰撞敌球拉近，每层最多 1.5u，两层最多 3u；接触玩家前停止，不穿过玩家。 |
| 一往无前 | 特殊，1 层 | 碰撞后保持原方向，最低保留 92% 速度；可与更高层的橡胶保速共同生效。 |
| 连锁反应 | 特殊，1 层 | 重击震伤 4u 内敌球，伤害为本次撞击的 30%，并将它们推开。 |
| 借墙发力 | 特殊，1 层 | 每次撞墙为下一击增加 60% 伤害，最多存 2 层，即最多增加 120%；命中消耗该球储存的层数。 |
| 黑洞引力 | 特殊，1 层 | 以恒定加速度 2.4u/s² 吸引 5u 内的可碰撞敌球；不吸动固定 Boss。 |
| 喘口气 | 特殊，1 层 | 击杀后 1.5 秒内，计划波次刷新间隔增加 50%，即刷新时钟以 2/3 速度推进；连续击杀刷新持续时间，数量地板仍补足。 |
| 分裂 | 特殊，1 层 | 本发第一次击杀后，保留主球并分出 2 颗半径 0.7u 的辅助球，沿入射方向两侧各 20° 飞出，速度为主球入射速度的 60%，伤害为相应主球参考伤害的 60%。 |
| 穿透 | 特殊，1 层 | 本发第一次击杀保留碰撞前速度；不额外改成直线穿行，方向规则与“一往无前”分开。 |
| 回旋 | 特殊，1 层 | 撞墙后 0.5 秒内速度提高 20%；期间再次撞墙只刷新时间，不重复乘 1.2。 |
| 震荡 | 特殊，1 层 | 本发每第 3 次撞墙，在实际触发的球处释放半径 3u 的冲击波，伤害为主球当前满拉参考伤害的 50%。 |
| 冒险 | 冒险，2 层 | 每层计划刷新速度乘 1.2、所有得分乘 1.5。两层分别为 1.44 倍与 2.25 倍；仍遵守 28 颗硬容量。 |
| 赌徒 | 冒险，2 次 | 下一阶段击杀目标乘 1.5 后向上取整；该阶段完成后的下一次奖励改为五选一，然后恢复普通三选一。再次获得可再触发一次，不永久叠加目标倍率。 |
| 狂潮 | 冒险，1 层 | 每波在原基础上增加 2 颗，最高可到 10 颗；波间休止乘 0.7，单发连击倍率上限由 8 提高到 12。 |

辅助球沿用本发的连击、借墙计分与强化反馈，真实击杀正常计分、推进阶段。它们没有额外的眼睛，仍由原主球接受拖拽输入。主球与辅助球共用本发震荡墙计数；由辅助球触发第三次撞墙时，冲击波在该辅助球处出现。震荡与连锁反应的实际伤害也算命中，不将只有范围伤害命中的发射误记为空发。

辅助球低于 3u/s 持续 0.4 秒后消失；下一次有效发射、清场或离开战斗会清除它们。轻点和取消拖拽不清除当前一发，暂停不推进辅助球运动与消失计时，旋转时按场地映射位置。

“冒险”是全局得分倍率，包括普通击杀、清场与旧 Boss 奖励；每笔最终分数四舍五入为整数。清场基础值仍为 10，因此无冒险、一层、两层时分别得到 10、15、23 分，不乘普通连击或借墙倍率。

## 奖励生成与长按

普通三选一的第一颗从常规池抽取，第二颗从未拥有的特殊池抽取，第三颗以 60% 概率抽冒险、40% 抽另一颗常规。五选一保留这三个位置，再增加常规与特殊各一颗。每次候选组合内不重复，已满层或尚未满足前置条件的强化不出现。

| 场上情境 | 权重变化 |
| --- | --- |
| 清场前剩余活敌球中，空心环与重球合计占比至少 30% | 橡胶、穿透、借墙发力的权重乘 2 |
| 下一阶段为 Boss 阶段 | 弹性十足、重量级、分裂的权重乘 2 |
| 上一阶段有有效发射，且平均每发真实击杀小于 1.2 | 分裂、连锁反应、黑洞引力的权重乘 2 |

情境在清场前保存，不因清空敌球而丢失；有效发射统计不含轻点与奖励选择区的弹射，真实击杀包含辅助球和范围伤害。多个适用条件可同时提高同一强化权重。

优先池耗尽时，从其他仍可获得的池补位；特殊池耗尽优先补常规。若只剩一两项，则只显示真实、不同且可获得的选项，不伪造重复球。全部强化满层时，跳过空的奖励选择，经过原有 1 秒奖励休止后进入下一阶段，不越过层数上限。

奖励球使用同一种颜色：常规没有外环，特殊一个细环，冒险两个细环；球下只显示名称。**长按奖励球 300 毫秒**可在球内查看点线与小球示意，松手立即消失。选择仍通过拖拽玩家撞击奖励球完成，长按或轻点奖励球不会直接选择，也不会在松手时发射。

按中奖励球后，该段选择物理暂缓，避免玩家余速在查看示意时撞选；松手后继续，不补算按住期间的运动。移动超过 8px、多指介入、取消触摸、失去指针捕获、暂停、后台、旋转、重开或离开选择阶段，都会清除预览。迟到的松手事件不会作用于新局。

反馈强度 0% 和系统减少动态效果仍保留长按示意，图内不运动；奖励类型与效果信息不会因反馈设置而消失。

## 获得后的下一发反馈

实际选完强化后，下一次有效的无尽战斗发射会带上一次“刚变强”标记。该发每次真实敌球击杀增加 2 片碎片，并将击杀音提高一级，之后的发射恢复普通反馈。辅助球击杀沿用本发标记。

轻点、取消拖拽和奖励区发射不消费待发标记。没有击杀的一发也会正常结束，不能无限保留到后续发射。清场扫除、Boss 普通命中与奖励、盾破和保命移除都不获得额外的强化击杀音或碎片。反馈强度 0% 不升调、不加碎片；系统减少动态效果继续遵守原有碎片预算。

## 直接试玩与验收

在 Site 地址后加 `?feedback-demo=1`，已有查询参数时加 `&feedback-demo=1`。试玩面板新增“强化试玩”选择器，包含“奖励三选一”“奖励五选一”和全部 18 项强化；选择后点击“试玩强化”。试玩通过实际获得强化与真实物理碰撞展示效果，不修改个人最高纪录、闯关或皮肤进度。

1. **三选一与五选一。** 先进入两个奖励场景，确认球互不重叠、名字可读，0/1/2 圈区分类别。长按一颗球超过 0.3 秒，观察示意；松手后拖拽玩家撞球，只获得一次强化并继续。Boss 后本版本仍只提供一次奖励选择。
2. **速度、质量和尺寸。** 分别选择弹性十足、超速、重量级、橡胶和大一圈。超速场景已先获得四层弹性，出手能超过原 60u/s 上限；大一圈不应只放大图形而保留小碰撞范围。
3. **击杀触发能力。** 磁吸、分裂、穿透和连锁反应场景预置可命中的目标。观察最近敌球拉近、两颗无眼辅助球、首杀保速、附近目标被震伤。分裂辅助球与任务 4 的敌方分裂子球应能靠颜色与数量区分。
4. **墙与持续作用。** 借墙发力、回旋、震荡场景先自动撞墙；留意下一击、短时加速及第三次撞墙的范围波。黑洞引力场景先不发射，附近球应向玩家靠拢。
5. **节奏与冒险。** 喘口气、冒险、狂潮场景允许实际刷新，观察击杀后的短时放缓、更快刷新与更多波次目标。赌徒场景已通过真实获得流程进入下一次五选一，不把所有普通奖励永久改成五选。
6. **下一发确认。** 正常选完强化后先轻点、取消一次拖拽，再有效发射击杀。该发碎片和音阶增强；第二次有效发射恢复。若该杀达标清场，增强只作用于真实最后一杀，清场声不再额外升一级。
7. **中断和屏幕。** 长按时分别移动手指、多指触碰、暂停、切后台、旋转与重开，确认无误选或松手补发。手机长屏、短屏、横屏打开三选五选及各强化场景，初始目标、外环和名称应处在试玩面板上方。
8. **成绩和旧玩法。** 试玩获得正分后通过暂停进入结算，最高纪录仍不变；从结算正常重开会退出试玩，新普通局恢复纪录保存。闯关自动强化、主页、选关、现有 Boss 仍按原流程运行。

本次同时按反馈把空心环轮廓由 1.5px 向内加厚到约 3px；外沿位置、物理半径和空心区域性质保留，出生时的小环会限制线宽以保留空心。
