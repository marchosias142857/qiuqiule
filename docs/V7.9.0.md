# v7.9.0：换装选择页与大眼萌

## 换装界面

- “你的形状”“你的外观”分别进入响应式卡片网格；内容淡出120ms、淡入120ms，头部与底部小球不卸载、不重置弹跳。
- 形状保留原有圆润多边形及形变过渡，依照实际拥有的6—15边形逐个显示锁定状态；关卡解锁条件仍为10—100关。
- “原汁原味”“自定义”“大眼萌”三张外观卡；自定义继续使用现有图片选择、裁剪和缓存，切到其他外观不会删除图片。
- 当前选择加粗。锁定遮罩为透明灰、白色锁和解锁文字；滚动区域固定在标题与小球上方横线之间，两端留白等于网格间距。
- 子页面返回箭头仅返回换装主页面，保持小球运动；玩法介绍也改用返回箭头。

## 大眼萌与解锁

- 色彩跟随设置中的玩家颜色，中心亮、外圈暗；首次及重新选用大眼萌时，仅玩家颜色切为浅绿 `#b8db8a`。
- 黑色圆眼直径为球直径的1/1.95，沿普通眼睛的视线方向以更大幅度偏移。满拉时约束圆眼与当前可见轮廓相切，不显示普通表情。
- UI、主页、选关、无尽、闯关、转场及奖励小球共用轮廓和眼睛计算。所有新绘制不改变半径、质量、速度、碰撞边界或发射参数。
- 原汁原味与大眼萌使用280ms淡化。连续切换继承当时的混合外观；透明图片退出时保留旧底色直至淡化完成。
- 正式无尽分数达到26767，立即持久化永久所有权和待展示奖励。结算时沿用关卡皮肤解锁的飞行、旋转、放大、光效及淡入弹窗；确认后清除待展示标记，不自动装备。
- 旧存档已有达标最高分也会解锁并补发一次弹窗；试玩和闯关分数不触发，旧自定义图片选择会迁移保留。

- 完整测试套件1019项通过；之后追加透明图片底色回归，最终受影响的257项测试通过。

- 生产脚本语法检查和差异检查通过。
- 浏览器预览核对390×780、320×568、740×360，验证响应列数、锁定与选中样式、返回、外观选择、固定小球区域；竖屏列表末端留白实测14px，与卡片间距一致。
