# v10.0.1 — 分裂母球潜在球数

> v10.0.2 补充：下文“被拦截位置改为普通球”已改为按当前阶段常规权重抽取其他合法敌种，排除母球，保留教学、敌种及单簇限制。簇长仍沿用每簇一次的独立抽选。潜在球数公式与其他规则不变。

按用户指定公式，移除原 v10.0.0 的每簇母球上限 2、全场与预排母球上限 3、后代预算 9，改为在每颗母球实际出生前检查：

`场上已有敌球数 + 已有母球数 × 2 + 3 < 28`

小于 28 才允许生成母球；等于或超过 28 时拒绝。已有母球本身已在敌球数中计过一次，加 2 表示其未来分成三颗的净增加量；最后的 3 表示此次待生成母球的潜在三个子球。

| 实际生成前的场景 | 计算 | 结果 |
| --- | --- | --- |
| 24 颗敌球，其中 0 颗母球 | 24 + 0×2 + 3 = 27 | 允许 |
| 25 颗敌球，其中 0 颗母球 | 25 + 0×2 + 3 = 28 | 禁止 |
| 18 颗敌球，其中 3 颗母球 | 18 + 3×2 + 3 = 27 | 允许第四颗母球 |
| 19 颗敌球，其中 3 颗母球 | 19 + 3×2 + 3 = 28 | 禁止 |

## 计数与刷新

- 适用于所有能够生成分裂球的阶段，不再以第 21 阶段为分界。
- 场上已有敌球包括尚在出生动画中的存活敌球，死亡残留对象不计入。
- 玩家、玩家分身、尚未出生的刷怪计划、暂存在队列中的子球不计入这个公式。
- 波次与补球通道均在实际出生时重新检查；同一帧生成多颗时，前一颗的出生会影响下一颗。
- 计划中的母球被拦截时，该位置改为普通球，保持原波次/补球数量。独立的母球生成请求被拦截时不创建敌球。
- 此条件只控制新母球；普通刷新、既有敌种数量限制和实际场上 28 球上限继续按原规则执行。因此它并不承诺后续普通球刷新也始终维持“潜在球数小于 28”。
- 已有母球仍分出完整 3 颗子球，空间不足时按原规则等待；子球即时可受伤和安全出生方式不变。

血量曲线、玩家分身强化、Boss、存档与音频没有修改。
