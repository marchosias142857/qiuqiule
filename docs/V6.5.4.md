# v6.5.4 · 每局随机与结算精简

## 每局独立随机

取消 v6.5.0 引入的每日固定种子。此前相同本地日期与相同操作会重放相同随机过程；现在每次正常开始、重开和快速重开都会获取新随机种子，不使用日期或当前毫秒作为种子。无尽模式的敌球位置、刷新、簇、敌种及常规、特殊奖励共用该局独立随机源。随机抽取仍可能偶然出现相同选项，不人为禁止重复。

暂停、后台恢复、继续本局和跨午夜都不会重置随机流。日期只用于本机每日成绩归档，跨午夜仍归开局日；历史最佳、每日纪录、里程碑、起步强化和皮肤存档保留。试玩继续隔离所有个人纪录。

同步版本号、导出文件名与离线缓存至 6.5.4；重建批准字体子集以覆盖“历”“史”。

- 实际敌球簇与强化采样器在不同局使用不同序列，表现层随机调用不干扰已开始的一局。
- 无 Web Crypto 时仍重新随机；跨午夜不改变当前局随机状态或成绩归属。
- 结算分数下方仅保留历史最佳；试玩、闯关、起步强化、Boss 双轮奖励和快速重开继续回归。
