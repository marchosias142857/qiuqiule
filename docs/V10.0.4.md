# v10.0.4 母球刷新与失败名额

按 2026-11-06 的更新要求，发布 v10.0.4 母球规则；v10.0.3 的 Boss 音乐提前准备修复保留。

## 刷新与分裂

母球恢复 v9.0.2（b5cac0574a5c6e1ba50e052859dc6645efbc91b7）的普通抽取规则，移除 `敌球数 + 2 × 母球数 + 3 >= 28` 拦截和替代抽取。阶段解锁、前三颗教学、同屏敌种限制、普通权重及簇长独立抽取保留。

保留 v10 的平滑血量曲线和子球安全出生：母球仍完整分裂为 3 个子球，子球无无敌时间、出生即可受伤，拥挤时只等待附近安全位置，不追溯已经结算的瞬时伤害。

## 失败计数

`liveCount` 保持实际存活球数；新增 `pressureCount` 用于满场名额。母球在出生时取得自身 body id 作为 `splitFamilyId`，三个子球及其待出生队列记录继承该 id。按家庭去重，不跨不同母球合并，不使用普通波次的 cluster id。

| 状态 | 该家庭占用名额 |
|---|---:|
| 母球存活 | 1 |
| 母球已死，三个子球尚在等待出生 | 1 |
| 剩余 3、2 或 1 个存活/待出生子球 | 1 |
| 子球全部消灭，无待出生子球 | 0 |

失败仍为 28 名额持续 0.8 秒，最后一颗子球死亡才可能解除这一家庭的压力。红边 24/26 阈值和压力眼神采用同一名额计数。波次与教学的容量门槛也改为此计数，避免实际球数 28、名额不足 28 时永久停刷。已有家庭的子球兑现不新增名额，满场也能完成分裂，实际小球数量因此允许超过 28。原有低球数补充节奏仍使用实际球数。

每局一次的保命清除最老 3 个名额；家庭年龄沿用原母球 id，同时移除活子球与待出生记录，不触发分裂、不计分。清场、奖励、Boss 转场及重开清理所有待出生记录，无额外常驻家庭表。

本次只合并满场名额。每颗球的碰撞、伤害、得分、连击、阶段击杀与清场奖励仍各自结算。

## 验证

覆盖家族全生命周期、部分/延迟出生、多家族隔离、28 名额阈值与宽限、末子击杀、超 28 实体继续刷新、满额时完整分裂、含纯队列家庭的整族保命、清场与重开释放、逐球积分，以及实际场景危险提示。既有血量、子球立即受伤/避让和 Boss 音频回归继续执行。

结果：全部 937 项自动测试通过、脚本语法检查通过；版本号调整后再次通过离线缓存专项回归。
