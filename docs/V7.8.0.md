# v7.8.0 — 主球撞墙隆起

将外边界撞击时的局部加粗、加深替换为平滑隆起。分身、普通敌球以及内部障碍物碰撞均不触发外框隆起；无尽、闯关和 Boss 场地的主球共用此行为。

## 参数

在审核方案上将高度与半宽同时缩至 5/6，坡角比例保持不变。u 是 `world.unit`，坐标使用 CSS 像素。

| 参数 | 普通 | 借墙发力 |
| --- | --- | --- |
| 满力度/100%反馈最大高度 | 7u/60 ≈ 0.116667u | 7u/30 ≈ 0.233333u |
| 半宽 | 2.5u | 3u |
| 满幅最大坡角 | 约 4.2° | 约 7.0° |
| 总时长 | 180ms | 300ms |

峰值乘以 `clamp((power−0.25)/0.75,0,1)^1.5 × 反馈强度`。默认反馈强度仍为 60%。减少动态效果时幅度再减半，借墙不出现反向回弹，总时长保留。

普通按 60ms 时间常数衰减，150–180ms 平滑收尾。借墙按 0–33ms 保持峰值、75ms 过零、150ms 内凹25%、225ms 内凹5%、300ms归零的节点作单调 Hermite 插值；没有第二次正向回弹。

## 绘制与四角

沿现有圆角边框的弧长使用升余弦轮廓，在接触点的外法线方向位移。隆起两端的位移和一阶导数都为零；固定接触法线使圆角与直线交界的切线连续。近角落的轮廓跨过原圆角连续展开，不绘制第二条原边框。开口端点平滑回到原位，不把洞口重新连接；尖角退化情形额外固定角点。坡度受10°保护上限约束。

所有输入边框、碰撞箱和球的坐标均保持只读。`border-bulge.js` 只产生绘制点；`arenaBounds`、碰撞半径、反弹系数、速度、计分和借墙增益不使用这些点。

## 事件与时间

- 外边界事件标记 `surface: arena`，内部借力障碍标记 `surface: obstacle`。
- 只有主球 ID 且非 `auxiliary` 的外边界事件可触发隆起。
- 无尽/闯关外边界的 `power < 0.25` 同时静音并不隆起；内部障碍的音效保留原规则。
- 首次真正渲染时固定在峰值，后续按扣除主球局部击杀停顿的世界时间推进；慢动作、暂停和后台处理与场景衔接。
- 同边再撞取新峰值与旧轮廓当前绝对高度的较大值，重新定位、计时，不累加；不同边可同时响应。
- 重开、退出、世界切换、屏幕尺寸变化、关闭反馈时清理状态。
- 撞墙不再叠加加粗或加深，包括撞墙触发冲击波时的旧整框闪光；冲击波本身和伤害保留。Boss击杀、危险提示等独立反馈保持原语义。

新增模块进入离线核心缓存，缓存版本、设置页版本、导出文件名与包版本同步为 7.8.0。
