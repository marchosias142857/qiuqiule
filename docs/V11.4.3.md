# v11.4.3 结算转场修复

自动失败、暂停后手动结算以及奖励弹窗结束后，重开和返回功能球均随结算面板淡入。场上的敌球留在原位淡出，不再成为结算按钮。

结算面板与敌球、首领、分身及碎片共用同一帧采样的 300 毫秒进度，避免独立 CSS 动画先完成、敌球仍残留。弹窗离场不会阻塞此进度，低帧率和后台恢复时也不会错开。玩家回位、皇冠与边框的既有动画保留。

## 验证

- 自动失败与手动结算分别覆盖无奖励、单个星迹、连续星迹、外观奖励，并各自验证常规与减少动态效果模式，共 16 种流程组合。
- 校验面板和场上球透明度互补，面板完全显示时场上球透明度为零；覆盖低帧率、长帧和后台恢复。
- 完整测试 1112 项通过；语法检查、静态构建和构建产物校验通过。
