# v11.1.0 磁吸与连击衔接

## 规则

磁吸仍为两层普通强化，每次击杀尝试牵引一颗合法敌球。新牵引在 0.25 秒内最多移动 3u（第一层）或 6u（第二层）；u 是初始玩家球半径。牵引只提供位置变化，不直接增加伤害或修改玩家速度/方向，伤害仍由正常碰撞产生。

高速时优先选择玩家前方、短促牵引就能进入行进路线的目标，将目标拉向玩家短期将经过的路线；低速或缺少合适前方目标时回退最近敌球。预测依据当下运动方向，并受场地边界限制。

最多同时牵引两颗不同敌球，两段各自保留剩余时间和位移预算。新击杀不覆盖或刷新已开始的牵引，两段占满时不额外排队；死亡/无效目标会被清理。分身和范围伤害击杀继续围绕主球触发，清场时清除牵引。

暂停、暂离和恢复进度保留牵引状态，尺寸变化同比缩放距离预算。旧版保存中的单段牵引保留其剩余时长与距离，后续新触发使用新规则。黑洞引力、敌方磁球、强化抽取及 v11.0.0 双风险防连续规则保持原行为。强化说明、本局强化摘要与试玩提示同步更新。

## 发布

版本 11.1.0，Android versionCode 110100。Site、GitHub 和 APK 使用相同的游戏资源；Android 沿用既有签名身份。验证结果在封存发布前记录。

## 独立机制核验

11750 组随机有效几何中，牵引总位移不超过对应的 3u/6u，单步不超过固定速度预算，牵引线段没有穿过玩家；中途反向后目标仍留在场地内，玩家位置与速度不被牵引函数直接修改。两段并行时第三次触发不会刷新已有预算，各自的局部碰撞停顿独立生效。

35 个刻意位于原行进路线之外的侧方目标对照中，40u/s 时旧版一/二层接触数为 5/10，新版为 22/31；60u/s 时旧版为 5/7，新版为 15/26。更近的身后目标不会抢走可拦截的前方目标。此为构造几何验证，排除了墙面/连杀等变量，不代表玩家实游命中率或通关率。

发布前完整回归：1030 项测试全部通过，脚本语法检查通过；新增 13 项覆盖前方可拦截目标、低速回退、两段并行、局部停顿、线段避让、墙面/转向、尺寸变化、两段完整存档恢复、旧单段迁移、慢动作及高速碰撞接续。
