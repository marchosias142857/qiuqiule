# 第二轮任务2 · 情境权重与强化说明（v7.1.0）

按用户v7.1.0指令，只实施“调整情境推荐权重”和“修正重量级等强化说明”。依据52页《球球了-第二轮-新版复查与改进方案.pdf》第6.2节（第30–31页）及N14表（第40页）。基线为已发布v7.0.0 Site提交`dfef7f25052da6ca93421ddb8105810ab96891b1`。

## 情境权重

上一阶段存在发射样本、每发击杀数为有限值且严格小于1.5时，分身有术、连锁反应、黑洞引力的抽取权重乘2。旧阈值为1.2，新增生效区间为`[1.2, 1.5)`；恰好1.5不加权，没有样本也不触发。

| 情境 | 原有规则与本批结果 |
| --- | --- |
| 空心环/重球占存活敌球至少30% | 橡胶、势如破竹、借墙发力权重×2，保持 |
| 下一阶段为Boss | 弹性十足、重量级、分身有术权重×2，保持 |
| 上一阶段每发击杀低于1.5 | 分身有术、连锁反应、黑洞引力权重×2，扩大适用区间 |
| 同时满足独立条件 | 仍相乘，例如Boss前且效率偏低时分身权重×4 |

权重影响同一候选池内的相对抽取机会，不是保证出现，也不是最终出现概率恰好翻倍。继续使用清场前的阶段快照；只改阈值，不改样本统计、清场和奖励接线。普通三选一、赌徒五选一、第三槽60%冒险类别、去重、层数上限与池耗尽回退均保留。

## 强化说明

| 强化 | 说明修正 |
| --- | --- |
| 重量级 | 明确每层质量×1.35、最多5层；无尽相同拉伸不降低弹射速度。 |
| 橡胶 | 明确保速为最低值；仍每层+6个百分点、最多4层，未击杀70%到94%，直接击杀85%起，第3层起最低100%。 |
| 一往无前 | 无尽撞敌球不改方向，至少保留92%速度，更高已有保速仍生效。 |
| 冒险 | 基础刷新速度每层×1.2、得分每层×1.5；两层分别1.44倍和2.25倍。 |
| 大一圈 | 仍是原始直径的1.2倍/1.4倍，明确不额外增加质量或伤害倍率。 |

PDF建议重量级描述为“对Boss伤害+35%/层”，本批没有无条件照抄。当前膨胀Boss的壳层收缩只受撞击速度等因素影响；同速撞击眩晕Boss的未取整伤害随质量提高35%，但进入眩晕时的HP快照也随质量提高。为避免暗示全阶段加伤或减少必需命中次数，游戏说明只承诺实际质量与发射效果。Boss逻辑完全未改。

所有18项强化的effect、requires、maxStacks、名称与类别等非说明字段逐项对比v7.0.0一致。未把任务4的冒险改加HP、橡胶+4/+8、大一圈+10%伤害或其他重平衡写成已生效。
