# v6.1.0 · 任务 2：无尽操作重做验收

> 历史验收记录：v6.5.2 已将瞄准子弹时间独立于反馈强度，并按第 7.1 节采用正常 0.3 倍、减少动态效果 0.6 倍的操作规则。本文中 0.58 倍默认慢放、0%／减少动态效果关闭瞄准慢放等条款及相关测试结果仅描述 v6.1.0；当前规则与本地统计见 [v6.5.2 说明](V6.5.2.md)。

本次只实施已确认计划中的任务 2：无尽普通战斗与 Boss 战的随时蓄力、限时慢放瞄准、松手重定向、撞击保速、分段阻力、轻点防误触和七点方向提示。本文用于现有 Site 的试玩验收，GitHub 和 Android APK 更新不在本次范围内。

## 操作与参数

| 项目 | 当前规则 |
| --- | --- |
| 随时接手 | 无尽 `battle` 与 `boss` 阶段不再按速度限制拖拽。按住不会额外刹停玩家，球与敌球继续运动。 |
| 轻点防误触 | 按下后先等待确认：按住满 120 ms，或拖动距离达到 6 px，才激活瞄准。小于 120 ms 且距离小于 6 px 的轻点不发射、不慢放。原地长按可激活瞄准，但松手位移不足 6 px 仍不发射。 |
| 慢放幅度 | 反馈强度默认 60% 时为 0.58 倍；100% 时为 0.3 倍；0% 或系统“减少动态效果”开启时为 1 倍。关闭慢放仍可随时转向。 |
| 慢放时限 | 从手势激活起，最低时间尺度最多维持 1.2 秒，再用 0.5 秒线性恢复到 1 倍。继续拖动不重置这次时限；恢复后仍可瞄准和松手发射。 |
| 松手重定向 | 方向取拖动反方向，速度取松手时的当前速度与拉伸补能结果；不累加按下时记录的旧速度。高速主要转向，低速可通过拉伸补能。 |
| 撞击保速 | 撞普通敌球后，沿碰撞解算得到的方向至少保留碰前速度的 70%；已有“一往无前”强化至少保留 92%，并继续保持原来方向。未增加新强化。 |
| 撞墙 | 无尽战斗中，玩家撞墙时被反射的速度分量保留 95%；碰撞边界位置不变。 |
| 分段阻力 | 玩家速度大于 8 unit/s 时，阻力系数为 0.35/s；降至 8 unit/s 或以下时为 1.2/s。跨过阈值的时间步分别计算两段阻力，避免因帧率而改变减速结果。 |
| 方向提示 | 固定七点。速度大于 20 unit/s 时，前三点沿当前速度方向并变淡，后四点及箭头沿松手方向；不超过该速度时，七点均沿松手方向。手指连线和两个端点圆环继续保留。 |

重定向的速度公式为：

```text
新速度 = max(0.9 × 当前速度,
             拉伸发射速度 × (1 − 0.5 × min(1, 当前速度 / 基础速度)))
```

拉伸发射速度继续使用现有拉距、能量、密度和发射上限，基础速度为 40 unit/s。`unit` 是随场地尺寸确定的游戏长度单位，轻点阈值的 `px` 是页面逻辑像素。

只有世界模拟随瞄准慢放。指针轮廓和照片仍逐帧响应，HUD 分数继续按原来的 250 ms 时限滚动；命中停顿使用真实活动时间，不因慢放拉长。物理步长仍为 1/120 秒。

## 保留的行为与范围

- 闯关保留速度门槛、拖拽刹车、按下时记录速度并在松手叠加的原操作，不启用瞄准慢放。
- 首页弹射、选关点击与圆环滑动、中央球原地回弹，以及奖励球选择，继续使用原操作。
- 只允许一个指针控制本次手势。第二根手指或另一设备的主指针不能接管，其他指针的松手或取消不会中断当前操作。
- 取消、丢失指针捕获、暂停、切到后台、离开页面、失焦、重开、战斗阶段结束或窗口尺寸变化，会结束本次瞄准并恢复正常时间；随后迟到的松手不会发射。仅像素密度变化不取消手势。
- 计分、阶段目标、刷怪、敌人种类、强化池、Boss 胜负条件和闯关玩法均保留当前规则。任务 3 及之后的连击、主循环、刷新、新敌人、强化与新关卡玩法尚未实施。

## “高速转向”试玩入口

在 Site 地址后追加 `?feedback-demo=1`；已有查询参数时追加 `&feedback-demo=1`。点击“高速转向”会重置为三个耐打目标，玩家立即以基础速度向右、略向上运动，不用先发射一球。

此场景与原来的轻击、重击、击杀、连续击杀、末球奖励、Boss 场景共用真实输入、物理和绘制流程。试玩得分不会写入最高纪录，也不改变关卡或皮肤进度；反馈强度设置仍会保存。点击“返回游戏”或正常重开后，恢复普通游戏的成绩保存。

## 建议逐项验收

1. **高速接手与转向。** 进入“高速转向”，球仍在快速移动时，在屏幕空处按住并拖动。球应继续运动，场景进入慢放。向下拉后松手，球应向上转向，保留大部分速度，不先停下再弹出。
2. **轻点与长按。** 快速轻点几次，不应发射或突然慢放。再按住约 0.2 秒，或立即拖动超过 6 px，确认进入瞄准。原地长按后直接松手不应发射；拖到明显距离后松手应正常发射。
3. **有限瞄准时间。** 激活瞄准后持续按住约两秒，期间继续移动手指。约 1.2 秒后世界应开始恢复速度，约 1.7 秒后恢复正常；拖拽形变仍立即跟手，松手仍可转向。
4. **比较强度。** 分别把试玩强度设为 60%、100%、0%。前两档应有不同慢放深度，0% 不慢放但仍能高速接手与转向。系统开启“减少动态效果”后重新载入，也应保持正常世界速度和转向能力；验收后恢复偏好的设置。
5. **检查方向提示。** 在高速向右运动时向下拖动，前三个淡点应向右，其余点和箭头向上；减速后七点都应指向上方。始终保留原手指连线及两端圆环。拖拽不推动边框，也不改变碰撞位置。
6. **检查连续碰撞。** 在无尽普通战斗中观察撞球、撞墙和减速过程。撞普通球后应更容易继续弹跳，墙面反弹仍明确；高速飞行维持较久，低速末段更快收尾。“一往无前”继续保留原来的穿行方向。精确比例由物理测试核对，目测用于判断操作体验。
7. **检查中断。** 瞄准时分别暂停、切到其他应用再返回、旋转设备或改变窗口大小，再尝试松手。不能残留慢放、蓄力音或意外发射。暂停后继续游戏需重新按下；重开应是完整的新局。双指操作时，第二指不能抢走第一指的方向。
8. **检查 HUD 与外观。** 使用圆球、多边形或照片拖动，轮廓与图片应跟手且不分离。慢放中击杀后，局部停顿正常结束、碎片只出现一次、分数及时收敛；HUD 和照片不应跟着慢放迟滞。
9. **检查原操作。** 回首页试玩功能球，再进入选关与闯关。首页和选关原有交互正常；闯关高速时仍需等球减速，拖拽时仍刹车且不慢放。无尽达到目标后的奖励选择也应正常完成。
10. **检查成绩隔离。** 记下普通游戏最高纪录，进入试玩产生得分并从暂停页进入结算，原纪录不应被覆盖；退出试玩后，普通游戏的新纪录仍能保存。

## 已执行验证

全套 `node --test --test-reporter=tap tests/*.test.mjs` 的 335 项测试全部通过，`npm run check` 和差异检查通过。其中 `restart` 套件的 85 项测试运行真实入口与场景逻辑，替换 DOM、Phaser 和音频设备边界；任务 2 覆盖高速 Battle/Boss 转向、120 ms/6 px 阈值、主指针独占、慢放时间、长帧、0%/减少动态效果、实时 HUD/照片、取消与页面生命周期、真实 resize 回调、七点指向、慢放期间击杀反馈以及闯关旧操作。

额外以不等长真实帧验证慢放与正常速度切换时的时间守恒、释放后的 33ms 冻结、80ms 击杀快照和碎片只生成一次；慢放末球进入奖励后，同帧剩余物理步骤立即恢复正常倍率，奖励按原定时限到达。

七个试玩场景均运行三秒并检查数值有效性。“高速转向”额外验证初始高速、取消不发射、松手仅转向一次；通过一次真实致命碰撞产生正分，再验证试玩及结算不会保存最高纪录。

浏览器检查了“高速转向”场景、拖拽和暂停，游戏页面未记录运行错误。

这些结果不等同于真机触控延迟、GPU 帧率、震动或扬声器听感验证。手机上的跟手感、慢放舒适度和连续试玩体验仍需实际设备验收。
