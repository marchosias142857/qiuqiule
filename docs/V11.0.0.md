# v11.0.0 风险强化连续出现限制

## 行为

每组三选一如果同时出现赌徒和狂潮，紧接着的一组三选一最多出现一个风险强化，提供至少两个合法、不重复的非风险强化。限制仅消费一组；随后恢复原有类别概率与类内权重，不追加风险补偿。Boss 的两轮奖励、赌徒带来的额外奖励均按实际候选组连续计数，不在阶段边界重置。

记录依据是展示出来的组合，与玩家最后选择哪一项无关。暂停、打开设置/强化面板、暂离及恢复上局不会消费或清除限制；开启新局重置。旧版进度在可恢复的双风险选择界面继续时，下一组也应受到限制；不改写已经展示的候选组合。

正常抽取保留现有阶段曲线：第 12～20 阶段逐步提高风险类别概率，第 20 阶段及以后不继续增长。限制时不新增强化、不绕过层数或前置条件、不放回已选择的同组强化；赌徒待生效时继续禁止再次出现。
