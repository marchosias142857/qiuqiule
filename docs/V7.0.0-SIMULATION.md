# v7.0.0 保留原刷怪的对照回放

本批保留阶段血量增长系数 **1.20**。在相同自动策略、8个固定种子下，它比v6.9.0延长平均局长约2.32分钟，平均结束阶段从11.38提高至14.88；比1.16和1.18候选更克制。此结论用于本批候选选择，不能解释为真人难度或附件原实验已复现。

## 来源与边界

- 基线：Site提交`a9ad79e4a32a48aaee691ad6d160cbd447c8ff1a`的`dist`，对应GitHub v6.9.0运行资源。
- 候选：本批N1击杀保速、N3重量级发射、N6普通重定向，加上1.16/1.18/1.20三个N4阶段血量候选。候选子类仅覆盖`enemyProfile().hp`，调用原方法后保留其随机采样、半径、密度及其他字段。
- 不改刷怪位置、环形布局、数量、波次、时间、敌种或分裂补生。不开启用户排除的N2、N5。
- 附件提到的`round2/sim/endless3.mjs`、`endless4.mjs`未提供。本脚本为新建、有界、可重跑的代理，不能与附件未复现的成绩直接合并。

## 方法

`scripts/simulate-v700.mjs`直接运行生产`World`。每版使用种子1–8，390×844场地，每局最多模拟30分钟，反馈强度0.6，每个真实模拟秒推进120次。瞄准持续0.6秒、世界速度0.3倍；清场和Boss胜利慢动作沿用游戏时标，物理内部停顿正常生效。

自动瞄准在90个方向中，选直接路径加一次墙面反射能够覆盖最多敌球的方向，然后叠加标准差10°的独立高斯误差。Boss直接瞄准中心。最多每分钟26发；速度低于12个单位/秒或距上次击杀至少1秒时才重新拉球，因此实际频率会更低。强化按固定优先级选择当前真实出现的候选，使用真实发射撞取奖励球。

全程仅通过拉球、发射和`step`推进，未写入伤害、阶段、胜负或奖励选择结果。Boss需要正常膨胀/缩小/眩晕并再次命中才能完成。逐步核对场上上限28、得分事件账本；每个模拟秒核对物体坐标、速度和半径有限。

## 统计口径

- **局长**：模拟的真实时间，包含瞄准、慢动作、奖励及转场；不是执行脚本消耗的宿主时间。JSON另存世界时间与战斗真实时间。
- **结束阶段**：游戏自然结束时的`stage`，并非已通关阶段数。
- **每发击杀**：普通战斗发射产生的直接或附带击杀总数÷普通战斗发射数；清场自动计分的`clearKill`不计入。
- **多杀占比**：至少杀2球的战斗发射数÷至少有一次命中、破盾或附带击杀的战斗发射数。
- **奖励余速**：成功奖励发射即清空上一发战斗归因；下次战斗发射前产生的命中、击杀单列为`rewardCarryHits`/`rewardCarryKills`，按发生阶段记录，不放进上一阶段战斗发射的分子。
- **前期**：阶段1–5合计后求比值，不是各阶段比值的平均数。第10阶段结果只含抵达该阶段的局，存在生存筛选，不适合单独解释难度变化。
- **Boss次数**：各局真实Boss结果总和；计时从`bossEntry`起，包含入场。直接中心瞄准使此代理的Boss结果偏强。

在此策略下，采用1.20时前期每发击杀较基线提高约13.1%，多杀占比提高约11.1个百分点，同时局长增长较两个更低血量候选小。三个候选均有同一套N1/N3/N6增益；此对照支持在保留旧刷怪时采用较高阶段血量增长，不能拆分出每个改动的独立因果贡献。

32局均因场上容量压力自然结束，没有30分钟截尾，也没有Boss失败。后者只能说明此直接中心瞄准策略能通过已遭遇的Boss，不能作为真人Boss通过率。

归因修正后，基线/候选1.16/1.18/1.20各8局共记录奖励余速命中12/73/59/51次，奖励余速击杀均为0。全部单列，没有归到上一发战斗发射。修正前后重新跑完32局，逐局核对阶段、分数、真实时间、战斗时间、世界时间、战斗发射数、Boss结果、强化路径及各阶段时间完全一致；本次样本的每发击杀和多杀占比也恰好不变。最终JSON及上表使用修正版。

校验通过：所有运行的上限、得分账本和有限数值断言通过；`node --check scripts/simulate-v700.mjs`通过。最终报告的当前物理SHA-256与生产文件一致：`d2f3613554bc617e2fcd2bc66fe1ab3b5788e36cb187d4617985622b45ea739b`。本次32局消耗约126秒宿主时间，与表中的模拟局长是两个不同的时钟。

## 复现

在保留基线提交历史的仓库根目录运行：

```sh
node scripts/simulate-v700.mjs --seeds=8 --max-seconds=1800 --growths=1.16,1.18,1.20 --out=docs/V7.0.0-SIMULATION.json
```

脚本自动归档基线资源到临时目录；也可用`--baseline-dir=/absolute/v690`指定本地基线。报告保存全部32局、实际强化路径、每阶段战斗时间、Boss结果、奖励余速统计及两版物理文件SHA-256。正式游戏仍逐局随机。

固定种子控制重现，但行为分叉后不同版本的随机调用会走到不同序列位置，因此不能把每个同号种子理解成逐帧相同的刷怪/强化。8局和单一升级/瞄准策略只足够做本批有界对照；未覆盖真人操作分布、不同策略、不同屏幕、手机触控或渲染帧率。本批不存在30分钟截尾，不需要把超时局误算为自然死亡。
