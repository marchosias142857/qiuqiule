# v6.2.0 · 任务 3：无尽节奏与计分验收

本次完成无尽普通战斗的聚簇波次、数量地板、击杀数推进、单发连击与借墙计分、连锁清场、压力边框、触顶宽限和每局一次保命，并换用改进文档第 10 节的数值曲线。任务 2 的随时转向继续保留。

本次没有加入新敌人类型、18 项强化池、新 Boss 或闯关新玩法。现有强化、Boss、首页、选关和闯关继续使用原有规则。本说明用于 Site 试玩；GitHub 与 Android APK 更新不在本次范围内。

## 计分与阶段推进

| 项目 | 当前规则 |
| --- | --- |
| 阶段目标 | 第 `s` 阶段需击杀 `14 + 4(s−1)` 颗普通敌球。HUD 显示本阶段击杀数与目标，累计分数不再触发阶段切换。 |
| 单发连击 | 同一次成功发射的第 `n` 杀获得 `10 × min(n,8)` 分，即 10、20、30……80 分，此后每杀仍为 80 分。下一次成功发射重置本发计数；轻点或取消拖拽不重置。 |
| 借墙加分 | 本发玩家实际碰过墙后，后续普通击杀得分再乘 1.5。这是通用计分规则，独立于“借墙发力”强化的伤害层数。 |
| 超额击杀 | 达标命中及同一批次震荡造成的超额普通击杀，结转到下一阶段。不会因清场额外跳关。 |
| 连锁清场 | 从达标击杀点向外传播碎裂波，速度为 20 unit/s。波触及的每颗剩余敌球固定加 10 分，音阶继续上行；不再增加本发普通击杀数或阶段击杀数，不乘连击或借墙倍率。 |
| 原有奖励流程 | 波扫完且最后命中的局部停顿结束后，才进入原来的 1.85 秒就位、两颗奖励球和 1 秒获得强化流程。每逢第 5 阶段，清场后先进入现有 Boss 战，再按原流程领奖。 |

例如，同一发普通击杀前三颗共得 60 分；若这三次击杀都发生在碰墙之后，则共得 90 分。两种情况都只推进三个阶段击杀。自动清场与保命移除的敌球，均不补充阶段击杀。

## 聚簇与新数值

`s` 为阶段，`t` 为本局世界累计时间，`unit` 为游戏长度单位。

| 项目 | 公式或时序 |
| --- | --- |
| 开局与阶段地板 | `F(s) = min(14, 6 + 0.5(s−1))`，敌球数量取满足地板的最小整数。开局六颗，第 2 阶段七颗。新阶段开始时一次补满本阶段地板。 |
| 地板补刷 | 数量低于地板立即开始成簇补充，其后每 0.15 秒补一颗，补到地板为止。 |
| 基础刷新间隔 | `interval(s) = 0.65 + 1.35 × 0.86^(s−1)` 秒。 |
| 每波数量 | `min(8, 4 + floor((s−1)/3))`。 |
| 簇的位置与节奏 | 簇半径 2.5 unit，波内间隔 0.3 秒；普通起波间隔为“本波数量 × 基础刷新间隔”。 |
| 新阶段首波 | 在两个基础刷新间隔之后到来；首阶段即约四秒后。 |
| 基础 HP | `19 × 1.16^(s−1) + 2 × floor(t/45)`。 |
| 基础密度 | `0.65 + 0.06s + 0.0004t`。 |
| 敌球物理半径 | 0.62–0.98 unit。 |
| 受伤外观 | 普通无尽敌球显示半径为 `r × (0.82 + 0.18 × HP / 最大HP)`；只改变绘制大小，碰撞半径不变。死亡残影和结算飞出也沿用受伤后的尺寸。 |

没有额外的低压或高压刷新闸门。28 颗是硬容量；容量已满时，当前计划刷新的位置会被消耗，不会积压成随后突然补出的巨大波次。“喘口气”保留已有持续时间与减速效果，影响计划波次，地板补刷仍保证有目标可打。

## 压力、宽限与保命

- **20 颗起提示压力：** 原边框逐渐更明显，透明度由 0.65 向 1.0、线宽由 1 向 1.5 变化，并最多混入 40% 敌球色。边框位置和实际碰撞墙不变。
- **24 颗与 26 颗：** 分别以 1.2 Hz、2.4 Hz 呼吸。24 颗起，启用表情时玩家会周期性瞟向附近敌球。
- **28 颗触顶：** 进入 0.8 秒宽限，按未暂停的真实活动时间计时；慢放瞄准不会延长它。期间击杀使数量降至 27 或以下，宽限立即重置。
- **首次宽限耗尽：** 最老的三颗敌球碎裂，不计分、不计击杀；消耗本局一次保命，玩家眼睛短暂睁大。换阶段不会重新获得保命。
- **再次宽限耗尽：** 正常进入结算。若最近 20 秒有未命中的发射，显示对应条数；否则显示本局新纪录或距纪录的分差。闯关和试玩不显示这条无尽个人纪录说明。

## 清场反馈与设置

清场慢放在满强度时为 0.3 倍，先保持 0.35 秒，再用 0.6 秒恢复到正常速度；默认 60% 强度对应最低 0.58 倍。清场波扫完可以提前进入奖励流程，无需等满整个慢放包络。清场推镜满强度最大 4%，已有击杀声、连续音阶和清场和弦共同表达这一阶段结束。

0% 强度或系统“减少动态效果”开启时，不慢放、不推镜。危险仍通过静态边框显示；减少动态效果时不呼吸、不加粗，只保留静态颜色提示。必要的阶段、计分和压力规则不因设置而关闭。

局部命中停顿、慢放计时和物理步进继续分开处理，跨倍率帧保留各自真实时间。暂停和切到后台会冻结清场进度并结束持续音；重开清除旧波、残影、镜头与保命状态。旋转或改变窗口尺寸时，清场波映射到新场地继续传播，旧屏幕坐标的镜头与残影清除，已经获得的分数保留。

## 可直接操作的验收

在 Site 地址后追加 `?feedback-demo=1`；已有查询参数时追加 `&feedback-demo=1`。除任务 1、2 的场景外，本次重点使用以下按钮：

| 按钮 | 操作与预期 |
| --- | --- |
| 连锁清场 | 自动完成阶段最后一杀。先看最后目标的命中停顿，再看碎裂波由近及远扫过八颗剩余敌球；每颗加 10 分，最终为 90 分。波扫完后才出现奖励选择。 |
| 压力保命 | 场上已有 28 颗。先不要发射，等待 0.8 秒；最老三颗自动碎裂，剩余 25 颗，得分与阶段击杀数均不增加。 |
| 危险宽限 | 保命已用完，先显示 27 颗，随后真实刷新至触顶。不操作应进入结算；重进场景并及时击杀，降回 27 颗应取消本轮宽限。 |
| 高速转向 | 检查任务 2 操作未回退：高速仍可拖动，轻点不发射，原手指连线及端点圆环保留。 |

建议再检查以下正常流程：

1. **开局与波次。** 正常进入无尽模式，开局应为一簇六颗，约四秒后开始首波；首波四颗逐颗出现，随后有明显波间隔。击杀使场上目标低于地板时，补刷应更快开始。
2. **分数与推进分开。** 同一发连杀、借墙后击杀分别观察得分；HUD 击杀进度每次仍只加一。第 14 次击杀触发第一阶段清场，不能靠更高分数提前触发。
3. **完整领奖。** “连锁清场”结束后，用原方法撞击一颗奖励球，获得强化后继续。第 2 阶段应有七颗开局敌球，目标为 18 杀。
4. **压力仍有补救。** 对比 20、24、26、28 颗时边框表现；边框不能移动或改变反弹位置。宽限期间救回一颗不会消耗保命；真正使用一次保命后，再次超时才失败。
5. **中断与旋转。** 清场中暂停、切到后台、继续，再分别测试旋转和重开。暂停时波与分数不前进；旋转后不留下旧位置残影；重开必须是六颗、零击杀、保命未用的新局。
6. **减少动态效果。** 将强度设为 0%，再用系统减少动态效果各试玩一次。清场与计分仍正常，边框保留静态危险信息，没有慢放、推镜或呼吸。
7. **已有模式。** 闯关仍按原有限敌球与击杀强化规则；首页、选关、Boss 和奖励选择保持原行为。Boss 命中仍无白光覆盖。
8. **成绩隔离。** 试玩得分及试玩结算不能覆盖最高纪录；从试玩结算正常重开后，应退出试玩，新普通局又可以保存纪录。返回游戏也恢复正常流程。
