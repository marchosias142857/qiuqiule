# v6.5.3 · 敌球辨识调整

本次落实用户指定的五项视觉修改。“磁球外圈，内圈都适当加速”结合“确保内圈仍比外圈细”的要求，按内外圈适当加粗实现。只更新现有 Site。

| 部位 | 新样式 |
| --- | --- |
| 重球 | 深色圈线宽从 1px 改为 2.25px。 |
| 分裂球 | 移除内部单圆环，改为保龄球式三个实心小圆，随球体旋转、出生和形变；颜色为 40% 黑色＋60% 敌球基础色。 |
| 敌方子球 | 颜色为 30% 黑色＋70% 敌球基础色，比 Boss 眼睛的黑色占比低 10 个百分点。 |
| 护盾球 | 外圈从 1px 改为 2px；破盾后仍移除外圈。 |
| 游走球 | 眼睛采用与 Boss 相同的预合成颜色：40% 黑色＋60% 敌球基础色，保持原来的看向玩家行为。 |
| 磁球 | 外圈从 1.5px 改为 2.5px，内圈从 1px 改为 1.5px；保持双层空心、内圈较细。 |

线宽以游戏 CSS 坐标计，不因屏幕像素密度额外放大。空心环原有向内加厚的 3px 样式保留。深色配色跟随敌球自定义基础色，不固定为某个主题色；子球战斗、受击冻结、击碎和清场碎片、结果过渡均使用同一色值，不影响玩家分身。

这是绘制修改：不改变碰撞边界、生命、重量、行为、生成阶段、子弹时间或分身存续规则。版本号、统计导出文件名与离线缓存同步至 6.5.3。
