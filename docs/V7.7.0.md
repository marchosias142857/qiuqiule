每类序号为 `rank20=2×floor((level−1)/10)+(level−1)%2`，取0–19。不是将旧十档重复两次；难度通过实际规则和布局变化递增。自动策略用时并不严格单调，不将模拟通关率当作真人难度曲线。

选择依据是与拖拉弹射核心一致、规则易读、五类体验互补、可扩展到20档。这是结合本作代码和附件的设计判断，不是经过玩家对比实验得出的“客观最好玩”。

- [Towards Minimalist Game Design，Nealen/Saltsman/Boxerman，FDG 2011](https://www.nealen.net/papers/tmgd.pdf)：少量机制、简单控制与抽象表现可以通过组合保留深度。
- [Atari：Breakout Beyond](https://atari.com/products/breakout-beyond)：清砖和通路变化具有多关卡扩展空间。
- [EA：Peggle](https://www.ea.com/en-ca/games/peggle/peggle)：清钉弹球、布局挑战和连续命中的配合。
- [Nintendo：Suika Game](https://www.nintendo.com/us/store/products/suika-game-switch/)：同类碰撞合成与防止容器溢出的双重决策。
- [Nintendo：WHAT THE GOLF?](https://www.nintendo.com/en-ca/store/products/what-the-golf-switch/)：简洁物理高尔夫操作可以承载不同关卡变化。

淘汰十瓶是因为当前固定瓶阵和轮次决策较窄；落砖与破墙重叠且有回收等待；碎屏更偏下落生存；当前弹珠缺少挡板主动操作，与钉板体验重叠；链球固定轨道、同级串消和链头终点增加规则负担，合成已承担自由球碰撞的连锁与压力体验。旧源码与历史测试保留，正式关卡不再调用这些玩法。

## 共用规则

- 普通发射4秒后判定收尾；仍超过6u/s可延长最多1秒，然后用0.3秒减速。落袋目标球同样参与判断；特殊回合接口保留。
- 五类共用场地框架与慢放强度规则；横竖屏旋转继续保持真实碰撞、预算和重叠排除。
- 关前显示目标、三点/两点标准及每项强化说明。场上固定三个评分点，显示当前相关量；完成目标后才真正计分。
- 各玩法首次通关前，重试及后续关的首发仍有教学；拖拽时保留提示线，并显示建议拉距。
- 主动重开和离开不清已累计失败；候选在看到后持久化，取消、刷新和重开不能刷候选；实际失败后重抽。
- 暂停/后台保留当前尝试；刷新或回收后恢复时单独记中断，不算主动放弃或真实失败。
- 可破目标采用敌方色实体，不可破障碍采用玩家色描边，功能区用背景与边线区分。失败按原因给不同声光反馈；叠层随退场渐消。

## 玩法修复

破墙：高速法向撞击超过20u/s时基础伤害为2；砖体回弹系数为1；每发第四砖庆祝一次；强化池用橡胶、弹性、借墙、重量级，避免穿透决定胜负。

钉板：早期11发、后段10发，桶宽从2.6u逐步缩至2.2u；混合花纹先于螺旋，螺旋置于最后四档。后段采用10发而不是附件原9发建议，是根据真实路线保留合理容错。接桶增加短和弦；首发提示在不同屏幕与强化下验证命中。

落袋：评分用量为发射数加自己落袋次数；高档预算至少13发，并确保独立两点区间；主球和目标球阻力均为0.3，过快袋口弹出有声音与表情提示。

推杆：不可破障碍改描边；中高档预算为标准杆加3，三点仍要求标准杆减1；配对第二关的路径更紧。

合成：采用随难度调整时间评分的方案，三点线 `60+4×(k+variant/2)` 秒、两点线 `90+6×(k+variant/2)` 秒。37%开始平滑压力预警，42%仍失败；3/4/5级球分别0/1/2内圈，合成快照中的内圈同步缩小淡出。
