# v7.11.2：伴星透明度与局内速度拖尾

- 分身统一应用60%不透明度，覆盖默认、自定义图片、大眼萌及淡出动画。
- 伴星本体不透明度从66%降至60%，尾迹基础不透明度从26%降至24%；保留连续渐变和单次透明度合成。
- 根据后续调整，仅撤回“所有情况都按玩家圆心位移记录实际路径”。恢复v7.11.1的场景范围：只有局内伴星记录实际移动轨迹；主页、选关、设置、暂停、换装、解锁、结算和转场恢复预设圆弧拖尾。
- 非局内、新世界、暂停和尺寸变化时清理局内历史，菜单使用相对小球的局部SVG坐标。速度加长、透明度、渐变和裁切保留本版实现。
- 局内沿用玩家拖尾的显示资格，以20u/s为增长起点、40u/s为最大增益，采用平滑插值将伴星拖尾从基础长度约0.966r延长至约2.898r。速度继续提高时不超过3倍；菜单、转场和静态卡片保持基础长度。
- 拖尾仍在伴星实际后缘裁切；轨道、自转、王冠层级、碰撞和物理状态不变。

## 首次发布验证

- 全量1075项测试及JavaScript语法检查通过。
- 伴星25项单元测试通过，覆盖速度门槛、平滑增长、上限、非局内隔离、同帧交接、渐变，以及最长拖尾的高速转向与后缘裁切。
- 游戏入口集成测试覆盖主页/选关真实位移、Canvas与SVG交接、换装弹跳、暂停、解锁、结算重试及奖励选择入关。
- 浏览器检查换装与暂停转场和高速飞行；拖尾沿真实移动方向延伸，菜单保持基础长度。未进行手机实机测试。
- 本次发布Site。

## 场景范围修订

- 仅回退非局内实际位移轨迹，保留20–40u/s局内速度增长和3倍上限。
- 游戏入口回归覆盖菜单预设圆弧、局内实际路径、暂停与新局清理，以及局内速度增长和非局内长度隔离。
- 本次范围修订通过276项伴星和游戏入口测试，以及JavaScript语法检查。

## Site 性能修订：第 1、3、5、6 项

- 分数动画仍逐帧推进。分数、缩放和辅助文字仅在显示值改变时写入；无尽模式的 10 个进度点、关卡模式的 3 个评分点在同一模式内复用，跨阈值当帧切换。
- 普通球仍绘制 192 段闭合轮廓。预先保存单位圆采样，同一姿态的顶点共用旋转参数；大眼萌只复用同一坐标系、同一姿态已算出的轮廓。保留自定义图片的形变缓存和分辨率。
- 解锁光效仍按当前半径和屏幕像素比绘制。尺寸不变时清空并复用画布，尺寸改变时按原规则调整；光效退场后，其临时缓冲缩至 1×1。图片裁剪可见时维持 768×768，取消或成功保存后缩至 1×1；保存失败保留当前图像以便重试。
- 与修订前的 Site 源码 `d60f0f2` 回放对照：七段共 1,353 帧，计分、物理状态、事件、随机调用次数和 1,933,106 条绘图指令逐帧一致。同一回放中，正余弦调用从 2,721,278 次降至 282,176 次，进度点整组重建从 751 次降至 5 次。这些是本次样本的工作量，不是手机帧率或进程内存测量。
- 浏览器 Canvas 2D 前后对照：15 帧球体、11 帧解锁光效、3 张裁剪图逐像素一致；覆盖光效像素比变化、退场复开及裁剪取消/应用。裁剪关闭时释放的单层 RGBA 像素容量约 2.25 MiB，实际内存回收由浏览器管理。
- 全量 1,076 项测试通过，无跳过；JavaScript 语法检查通过。验收浏览器未提供 WebGL 上下文，手机 WebGL 显示、实际帧率及进程内存留待实机验收。

## Site 性能修订：第 2、4 项

- 菜单伴星复用 SVG 路径；选关页保留仍在视野中的小球和返回图标，滚动时按关卡编号增减。与上一个 Site 版本 `b2199ba` 相比，菜单中的「月·三」旋转 60 帧，原先重建的 5,940 条路径现在全部复用。
- 玩家、分身和伴星拖尾复用有上限的历史与几何缓冲。公开几何函数的结果仍可跨帧保存。针对高速急转、同帧改位、暂停和重开的对照中，166,732 个伴星裁切顶点逐点一致。
- 1,084 项自动测试通过。浏览器对照了 82 组菜单伴星、25 帧选关画面和 221 个局内 Canvas 2D 图层，涵盖换装淡出后重选、选关重开及横竖屏切换，像素差为零。手机 WebGL 表现、帧率和实际内存占用留待实机验收。
