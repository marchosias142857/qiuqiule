# v11.4.1 星迹解锁弹窗加更

基线为音乐自检后已发布的 v11.4.1，提交 `ce44510e19ebd016fd5608f693d7d96695b59d49`。按用户要求保留同一版本号。

## 后续布局与金光调整

在首版星迹弹窗 `dbe124199e01d7ca9085d69f475f3128d50167ff` 上，根据演示反馈收小整个组合，使静止展示时拖尾左端与小球右缘相对弹窗中线严格对称。入场停靠点按完整小球边界预留弹窗内侧余量，而不是仅避免超出屏幕：342 px 弹窗中球半径从约 46 px 减为约 33.54 px，停靠时球左缘距弹窗左边约 27.36 px。

按最新要求恢复原有金光绘制，固定在弹窗竖直中线与拖尾横轴交点；与拖尾展开同步淡入，连续星迹切换保持亮度和位置，收尾时淡出，不跟随小球飞向结算。旋屏时金光横坐标取新弹窗中线、纵坐标取当前帧拖尾轴，避免过渡期间短暂错位。此要求覆盖首版“移除金光”的处理。几何计算与演示共用同一函数，保持等比缩放与所有粒子/拖尾参数。

后续调整验收：390×780 竖屏的起点、完整展示和星迹交叉淡化均经实际浏览器检查；780×360 横屏布局也已检查。全套 1,089 项测试通过；补齐旋屏轴线修正后，242 项场景集成测试再次通过（含普通/减少动态下切换和收尾中途旋屏）。语法及构建检查通过，最终产物为 53 项资源、40 个脚本，14 项非压缩资源逐字节一致，临时验收入口未进入产物。交互演示直接打包本次几何、动画、粒子和金光函数，已验证九种星迹依次点击、完整退场及重播。

## 首版完成内容（布局和金光以上述后续调整为准）

- 星迹奖励直接复用 `WardrobeShowroom`：相同的九层薄拖尾、三颗固定位置粒子、2.8 秒呼吸节奏及形状绘制。解锁界面独立持有渲染实例，避免与换装页混用 SVG 宿主。
- 按弹窗宽度和手机可视范围放大组合。390 px 竖屏样例半径约 46 px；动画停靠点留出视口边缘余量，不裁切小球。横屏按实际方形弹窗重算布局。
- 入场先用换装页的同一移动轨迹到拖尾末端，0.28 秒后用 0.26 秒移向展示位置并拉出拖尾，粒子随拖尾逐步显现。保留移动过程本身的滚动，取消旧解锁独有的原地三圈旋转。
- 连续星迹保持完整拖尾、小球、标题和呼吸时钟；只对上一种、下一种粒子做 0.18 秒交叉淡化，与星迹页选择切换一致。一次有效点击仅确认一项；切换未完成时不接受下一次确认。
- 最后一项先以 0.18 秒从拖尾末端向球体收回，再用 0.32 秒移动到结算位置。结算及其控制球等到拖尾收完才开始转场。
- 星迹奖励完全不绘制背后金光；前一项若是大眼萌外观奖励，其金光在转入星迹时释放。外观奖励本身保留原有展示。
- 减少动态设置继续生效：靠近/拉出分别 0.16 秒；收尾/离场分别 0.12/0.22 秒；粒子不呼吸摆动。
- 每项确认及时保存，刷新不会重播已经确认的项；未展示项保留。展示不改变已装备外观、自定义图片、星迹或玩法进度。

## 首版浏览器验收

使用本地临时页面操作实际游戏模块，支持定格检查；临时入口和测试控件不会进入最终构建。

- 390×780 竖屏：检查入场起点、0.28 秒末端停靠、0.54 秒完整展示，三颗粒子与薄拖尾完整，无金光。
- 逐次切换：0.09 秒时两种星迹各为 0.5 权重、各三颗粒子；0.18 秒只保留新项。球位置/半径和完整拖尾不变。

- 混合奖励：大眼萌外观奖励后接连续星迹，恢复原外观，未残留金光。
