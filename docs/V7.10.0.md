# v7.10.0：大眼萌反馈修复与伴星

## 大眼萌修复

- 拖尾及拖拽提示线原本仍在采样和绘制，但浅绿色叠加低透明度后在浅色背景上难以辨认。现在只对大眼萌的反馈用色按背景对比度调整明暗，保留同色相、点数、几何、透明度、速度门槛及物理行为；原形和自定义图片用色不变。
- 进入大眼萌前保存 `previousPlayerColor`，卸下或上传自定义图片时恢复，快速切换与刷新不会覆盖该快照。
- 兼容限制：7.9已装备大眼萌的旧存档没有记录当时原色，第一次卸下使用默认黑色 `#252720`；之后按新记录准确恢复。

- 选用、替换、重复点击卸下均为180ms淡化，连续快速切换从当前权重继续；不重置玩家动作和环绕时钟。
- 伴星尺寸约为玩家半径的0.21，轨道与真实视觉轮廓外偏移约0.5r，每3.4秒一周，多个伴星按轨道弧长等间距分布。
- 轨道与小球的多边形、换形、旋转、拉扯、挤压及飞行形变共用当前外轮廓；拖尾沿相同轨道，复用玩家彗尾的九条横向明暗带和截尾逻辑。
- 伴星半透明、颜色随玩家并在外观淡化时混色，外深内浅；实际形状为圆、月牙或四角星，无外描边。
- Canvas先画伴星再画玩家和王冠；独立UI伴星层低于玩家/王冠层。主页、选关、两种游戏模式、换装、结算及转场共用视觉状态。
- 不创建物理实体，不参加碰撞、伤害、计分、墙面隆起；分身不复制伴星。
