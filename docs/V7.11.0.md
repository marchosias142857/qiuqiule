# v7.11.0：反馈统一、伴星轨迹与换装整理

## 提示与分身

- 自定义图片皮肤原本仍有提示线及高速拖尾绘制，但反馈颜色取自图片下的小球底色；底色接近背景时难以辨认。提示线现在统一使用文字色，图片皮肤拖尾沿用大眼萌的背景对比度保护；图片画布在轮廓外保持透明。
- 分数、阶段进度点、Boss分段/击杀加分、各玩法拖拽提示统一为浅底深色 `#252720`、暗底白色 `#f0f2e8`。新纪录保留声音与缩放，不再随小球颜色变化。
- 分身在公共绘制入口使用80%不透明度，与现有出生/退场透明度相乘，覆盖圆形、多边形、图片、大眼萌和结算快照。

## 伴星运动

- 局内从最终绘制位置记录每颗伴星的实际世界路径，包含玩家位移、环绕以及轮廓形变；首次出现从空尾迹自然增长。菜单与静态展示保留环绕轨迹。
- 伴星以12点位置的原始姿态为零角度，自转角随实际“玩家中心→伴星中心”方向改变，同一面始终朝向玩家，适用于多边形轨道。
- 每帧依据实际运动方向计算伴星后缘，裁掉本体内部、前方及穿越本体的尾迹；月牙与四角星使用实际轮廓，并非不透明覆盖或外接圆裁切。九条明暗带的裁切片段重新拼接，避免接缝叠色。
- 历史路径只存独立坐标，不写入物理对象。重开、世界切换、离开局内、弹窗接管小球、后台、改变画面尺寸、异常位置跳变均清除旧轨迹，卸下或替换时清除对应历史。
- 路径保留有限历史，并在生成尾带时做小于0.005r的几何简化。轨道仍与小球轮廓等距，伴星仍在王冠下方，分身不生成伴星。

## 换装与设置

- 主换装页隐藏预览小球上方的横线；进入形状、外观、伴星子页时在240ms转场内淡入，返回主换装页时淡出。小球预览布局与运动连续。
- 删除“多边形皮肤”开关。形状网格第一项为始终解锁的“圆形”，圆形/多边形共用选中加粗规则与原换形动画；未解锁多边形仍显示锁定卡片。切回圆形保留最后选用的多边形与所有权。
- 设置标题改为“你的球，你的定义”。删除瞄准记录、闯关记录导出按钮及入口，保留本地瞄准校准和进度记录。
- “恢复默认”位于玩法介绍下方，重置小球/敌球/背景颜色、声音、震动、表情、音乐/音效音量和反馈强度，并同步控件与存档。保留关卡进度、最佳成绩、图片、形状、外观和伴星。装备大眼萌时，底色恢复快照也更新为默认色，避免之后卸下皮肤撤销重置。

## 验证与范围

- 真实入口集成测试249项通过，覆盖自定义图片、深浅主题、新纪录、Boss加分、四类分身、实际位移尾迹、历史清理和默认设置持久化。
- 伴星模型22项通过，包含高速移动、曲线、反向、形变多边形、16个运动方向、后缘接触、内部/前方无尾迹及30/60/120fps对照。
- 换装交互14项、外观模型13项通过；语法检查通过。
- 三个月牙伴星、连续变形及高速曲线路径的本地200帧测试平均2.38ms、P95为6.90ms；不代表手机实机性能。
- 全量1068项自动化测试通过。浏览器检查390×780与320×568的设置、形状网格和锁定状态，确认横线切换、默认设置控件更新、自定义图片在深浅背景的可见拖尾，以及进度点与分数同色。
- 仅更新Site源码和部署；不更新GitHub或Android APK。
