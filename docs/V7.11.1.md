# v7.11.1：细化伴星内部渐变

- WebGL本体改用连续顶点颜色插值，消除原四段色带的硬切换，保留原有几何和顶点数量。
- Canvas回退将本体细化为24条互不重叠的色带；菜单和静态卡片使用24层不透明嵌套填充，再对整个伴星应用一次透明度，避免细缝和叠色变实。
- 本体维持初版66%不透明度，尾迹维持26%基础不透明度；换装淡化仍与这些值相乘。
- 轮廓、尺寸、等距轨道、自转、实际路径和后缘裁切均未改变。

## 验证

- 伴星、真实游戏入口和换装286项测试通过。新增连续顶点颜色、覆盖面积不重叠、渐变状态恢复、SVG透明度单次合成检查。
- 与v7.11.0逐项比较540个伴星帧：位置、姿态、轮廓、运动历史及全部裁切后尾迹顶点完全一致；初版透明度常量保持一致。
