## 验收方式

1. 检查设置页显示7.0.0，开局仍只选择一个常规强化，敌球仍按现有方式出现。
2. 相同拉距比较未拿重量级与拿重量级的发射，重量级不再使出手变慢；连续杀球后的速度保留更明显。
3. 无尽普通战斗高速飞行时轻拉改变方向，确认不额外扣掉10%速度，仍有正常阻力。
4. Boss继续膨胀、缩小、眩晕后再击杀，奖励与王冠流程正常；抽测原闯关玩法、旧进度与皮肤。
5. 本批完成后停在第二轮任务1验收，不继续任务2。
