# v10.1.0 暂离与进度恢复

## 交互

暂停菜单下排为左侧“结束本局并结算”、右侧黄色“暂离并保存进度”。暂离球采用圆角向右箭头和竖线，复用现有功能球的统一 SVG/Canvas 几何。

首页开始游戏时若有有效进度，先进入独立的奖励球式选择场景。两球下方为“新的一局”和“继续上局”；前者使用原有重开图案，后者使用圆角双实心三角形。用玩家球弹射撞击选取，临时场景不计分、不发强化、不消耗原局随机流，也不覆盖原局存档。新的一局会清除旧进度并正常进入一次起步强化；继续上局还原原位置后再恢复运行。

## 保存和消费

只保留一个本地活局槽 `qiuqiule-run-save`。暂停、blur、visibilitychange(hidden)、pagehide 和 beforeunload 同步保存；已在暂停设置/帮助/本局强化内，以及恢复入场尚未完成时，再次离页也能保存。继续暂停局或消费存档时删除对应快照，之后再暂停写入新快照。首次主页、已结束的游戏及临时两球界面不创建活局快照。没有增加隐藏的持续自动存档槽。

取消当前指针手势后再保存，避免恢复已经不存在的 pointer capture 或持续拉扯。暂离写入失败留在暂停页；主动结算删除失败不销毁活局，提示重试。自动死亡不能回退，先删除存档；若删除失败但仍能写入，则使用独立终局标记使旧进度不可读取。读写都不可用时提示实际失败，不宣称已经持久化成功。

## 恢复内容

完整保留 World 自有字段和运行日期、种子、PRNG当前位置：位置、速度、血量、强化与层数、一发内使用标志、连击/分数、阶段进度、保命、满场宽限、刷球安排、分裂家族与待出生队列、Boss接触集合/半径/生命和奖励轮次等。图编码支持 Infinity、Set、Map 和共享引用，尤其 activeShot 与 shotHistory 仍指向同一对象。直接恢复 World 原型，不通过构造器重刷怪或重新抽奖励。

同时保存物理 accumulator/timeSlices、奖励成长/飞行过渡、反馈时钟、粒子与文字描述、危险提示、拖尾、阶段HUD和本局纪录提示。Phaser资源和DOM不进入存档；文字按描述重建，世界引用重新绑定。相同尺寸直接恢复；尺寸改变时按原有resize规则适配场地，并重建依赖旧视口的装饰。音轨按恢复阶段选择，Boss阶段会直接请求Boss曲，不依赖已消费的入场事件。

恢复入场动画结束后给予1秒慢速：普通为0.3倍，减弱动态效果为0.6倍；与清场/Boss固有慢速取较慢者。只在前台、未暂停的游玩时间扣除秒数。轻点的待判定阶段继续保持入口慢速；实际拉动或按住激活AimGesture后结束入口额度，使用手势自己的完整慢速预算。奖励选择阶段的有效普通拖动也会结束入口慢速。

## 离线修复（同版本加更）

线上实测 Site 的 `/index.html` 返回 HTTP 307，Location 为 `/`。旧离线清单同时强制下载根目录与 index.html，并使用 `redirect: 'error'` 防止缓存登录页面，因此必需资源安装整体失败。移除重复的 index.html 下载，仅缓存直接返回 200 的规范主页；访问根目录、index.html 以及带查询参数的主页均继续从同一份缓存恢复。保留登录重定向与错误资源校验，并更新离线缓存代次以触发重新安装，不改动本地存档键或游戏版本号。

回归用例复现根目录与仓库子目录托管的重定向：修复前两项安装失败，修复后可完全断网加载主页及全部游戏模块；认证跳转仍会拒绝安装并保留前一份完整缓存。首次完成离线安装仍需联网打开游戏并让必需资源下载完成。

## 分数入场修正（同版本加更）

主页撞击开始球进入动画时就读取有效存档；需要选择新局/继续时，从动画首帧起隐藏左上角分数，并在选择期间保持隐藏。选定任一分支后，分数才从透明开始，采用正常主页入场相同的 0.15 秒延迟与 1.05 秒 ease 淡入。仅控制分数，不影响选择文字与其他 HUD。无存档直接开始保持原来的入场动画。

验证：现有主页、重开、存档选择与离线相关 270 项测试及语法检查通过。浏览器确认入场动画两处中间时刻和选择界面均隐藏分数，继续后透明度从 0 经中间值到 1；使用临时按钮推进动画，验证页已移除。

## 暂停键位置修正（同版本加更）

暂停键使用独立的自动左边距固定靠右，不再依赖分数占位来维持两端对齐。需要新局/继续选择时，从主页进入选择的动画首帧起隐藏暂停键，整个选择期间持续隐藏；选定后恢复显示与可用状态，仍固定在右上角。不需要选择的普通开局保留原有暂停键入场。
