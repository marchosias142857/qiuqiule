# v6.5.6 · 奖励出场与 Boss 击杀反馈修复

## 奖励出场过渡

此前奖励名称在出场阶段固定为 40% 不透明度，切换到可选阶段时重新创建标签并直接设为完全不透明。标签上的 CSS 过渡无法跨越新旧节点，造成字体突然变实、视觉上变大的闪烁。

现在同一轮奖励持久复用标签节点，透明度逐帧跟随奖励球的 `born` 出场进度。进入可选阶段时不重建标签，也不重设字号；字号仍由当前布局确定，横竖屏或窗口尺寸变化时正常重新布局。奖励球的轻微浮动渐入，消除阶段切换时突然出现的上下偏移。

奖励球原有的尺寸渐变继续使用同一出场进度。开局选择、普通阶段奖励、赌徒五选一与 Boss 连续两轮奖励采用相同展示规则。

## Boss 击杀反馈

修复 Boss 击杀时主边框静止、仅附加副框抖动的问题。现在当前缩小后的方形场地只有一条主边框，该边框本身按击杀反馈产生视觉偏移；实际碰撞边界位置不变。

Boss 最后一击保留真实接触点、碰撞法线与入射速度，沿撞击方向喷射与普通敌球击杀相同的碎片。碎片数量按 Boss 击杀时的半径与普通球平均参考半径 `unit * .8` 的比例增加，当前约为普通参考球的 2.5 倍；保留 120 总粒子上限及减少动态效果下最多 5 片的限制。

## 玩法范围

本次调整视觉过渡与 Boss 击杀反馈，不调整球体出生时长、可选时机、碰撞边界、碰撞半径、奖励抽取和强化效果。开局固定一次选择、赌徒下一轮五选一、Boss 胜后双轮奖励及存档保持原规则。版本显示与离线缓存同步至 6.5.6。
