# v11.4.0 性能、内存与发布体积优化

基线：当前 Site v11.3.2，源码提交 `0f3d6d2afe0f74207c12accdfa97686dbb5a306c`。
审查覆盖全部 39 个第一方运行脚本、HTML、两份 CSS、离线清单、字体/音乐/图标资源与发布配置。Phaser 与 Capacitor 版本保持；第三方引擎未重写。

## 实施项目

1. 玩家/分身复用 192 点轮廓，特殊敌球复用投影与局部轮廓缓冲。弱引用随球体/渲染器释放，不让缓存延长一局的生命周期。
2. 奖励球直接写入圆周坐标；大眼萌 Canvas 回退路径直接绘制三角形坐标；不可见的 Boss 表情不生成几何；边框形变的公共最大值每次只算一次。
3. 物理子步用循环替代速度/计数/间距临时数组。轴向间距已足够远时跳过距离开方，实际接触仍执行原碰撞求解和原顺序。无磁吸时跳过时间 Map 和路线计算。固定敌球引入元数据只初始化一次。
4. 首页功能球从中间克隆改为直接构造最终四个对象。
5. 星迹复用临时列表与绘制参数，粒子阻尼每步共算；回收粒子时清除 owner，避免闲置对象保留旧球体引用。保留随机调用顺序、粒子数、尺寸、时间与轨迹。
6. 特殊外观对比色增加最多 16 项缓存；换装中静止的薄拖尾保留已生成的 SVG 路径，三个图案仍按原时序呼吸。自定义图片复用绘制帧/键，只写变化的 CSS 长属性。
7. 普通音乐解码成功后释放 2,909,100 字节压缩副本；持续播放的 PCM/时间轴保留，Boss 压缩数据仍供后续重新解码。
8. 相同 MP3 使用按 SHA-256 内容区分的共享离线缓存。迁移成功并接管客户端后才清理旧副本；保留上一代核心代码。配额不足时保留并读取原有音乐，接管失败不清理旧缓存。相对两代完整音乐缓存减少 5,164,280 字节。
9. 新增可复现的发布压缩：`npm ci && npm run build && npm run verify:build`。可读源码在 `dist/`，Site 部署 `build/`。只压缩第一方 JS 的标识符与空白，关闭表达式改写；音乐、字体、图片、HTML/CSS、引擎与许可证逐字节保留。Terser 为开发依赖，不进入游戏运行时。

## 行为与画质边界

保持碰撞、伤害、速度、随机序列、刷怪、分数、强化、存档、音乐时长/音量/音质及所有现有效果。没有减少轮廓点数、画布分辨率或粒子数量。v11.3.2 分身拖尾按真实形变轮廓裁剪的算法保持，并通过原汁原味、大眼萌、自定义外观及受击位移回归。

## 验证证据

- 原版全套：1,067 项通过；优化后全套：1,078 项通过，零失败/跳过。
- 物理差异模拟：30 个固定种子场景，24,026 帧完整状态、5,201 条事件与基线一致；首页 12,000 帧一致。
- 接触边界：10,000 组新旧配对，包含轴向、相切附近、出生半径、重叠状态，全部一致。
- 渲染差异：160 组特殊敌球姿态、12 组大眼萌 Canvas 姿态的绘制指令一致。
- 外观差异：9,000 个配色输出、19,200 步粒子状态、600 帧换装 SVG 输出一致。
- 定向测试覆盖缓存迁移/失败/跨版本复用、音乐重复缓冲释放、缓冲区所有权、图片失效重绘和粒子回收。
- 构建验证解析全部发布脚本、检查模块引用、资源清单一致以及所有非压缩资源字节一致；压缩物理模块另外对照同一基线模拟。

## 测量解释

相同环境、交替新旧版本的局部 Node 测量：特殊敌球绘制 56.08 → 46.59 ms/100 帧；大眼萌 Canvas 回退 21.53 → 16.85 ms/100 帧；物理模拟中位数 1491.30 → 1436.22 ms。它们是隔离子系统的 CPU 耗时，不是手机整机 FPS 或整机内存测量。

稳定主球与两个分身每帧少分配 576 个轮廓点对象；大眼萌 Canvas 回退每次绘制少分配 12,096 个临时顶点对象。实际进程内存下降取决于浏览器垃圾回收、Canvas/WebGL 与设备环境。发布文件体积和离线缓存重复量分别报告，不相加冒充安装包压缩量。

仅更新 Site；未发布 GitHub Pages 或构建 Android APK。

## 最终发布体积

原版资源 7,135,909 字节 → 发布版 6,943,839 字节，净减少 192,070 字节（2.69%）。第一方脚本相对本版可读源码压缩 38.33%；相对原版脚本从 516,391 → 324,321 字节（37.19%）。音乐/字体/图标及引擎保持原字节。共享缓存与压缩字节释放量不包含在这项发布资源统计中。
